# MyPoGoCompanion — app map

Approved by the owner on 2026-10-27 (stage 10.1). Every screen is designed at **phone and desktop size** before approval.

## Navigation

Phone: bottom tab bar. Desktop: left sidebar with the same sections.

| Tab | What's inside |
|---|---|
| **Today** (home) | What's on now: raids, Max Battles, events, eggs & research; links to the calendar |
| **Pokédex** | All Pokémon, each Pokémon's page, moves, the type chart |
| **Battle** | Raid bosses and counters, tier lists (PvP and raids), best teams; later Max Battles, the simulator, Team GO Rocket |
| **Filters** | Keeper filters, the filter builder, your saved filters |
| **Collection** | Your Pokémon, upload and import report |

Always on screen: a **search bar** (any Pokémon, move, boss or event), an **Ask** button (AI chat), and **your profile picture** (Sign in, Settings, Admin for admins).

## Entry points (agreed during screen review)

- **A2 Calendar:** "Calendar" link in Today's Events section; a **calendar button in Today's header** (phone); Calendar in the desktop sidebar; **search** offers the Calendar for words like "calendar", "raid hour", "community day" (H2).

Post-MVP screens (Max Battles, simulator, Team GO Rocket, trading, routes, data corrections, etc.) are added to this map when their features are scheduled.
