Keeper Filters

Copy-paste storage searches that find the Pokémon worth keeping. Paste a string into the search bar of your Pokémon storage, select all results and tag them.

Search keywords are in English: set the game language to English, or the strings will not match.

Data: PvPoke game master and rankings (MIT licence) as of {{DATE_PVPOKE}}; raid move stats from the datamined game master as of {{DATE_GM}}. Page built {{BUILT}}.
